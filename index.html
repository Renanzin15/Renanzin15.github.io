app.py · rota de cadastro (código real do projeto)
@app.route("/adicionar", methods=["GET", "POST"])
def adicionar():
    if request.method == "POST":
        nome      = request.form["nome"]
        categoria = request.form["categoria"]
        quantidade= request.form["quantidade"]
        # ... unidade, preco

        novo_produto = {
            "nome": nome,
            "categoria": categoria,
            "quantidade": quantidade,
        }
        produtos.append(novo_produto)
        return redirect("/")
    return render_template("adicionar.html")

Conceitos que domino aqui

  • Rotas Flask ligando URL a função (@app.route)
  • Diferença entre GET (ver) e POST (enviar/criar)
  • Ler formulários com request.form e redirecionar
  • Separar Python do HTML com render_template + Jinja
  • Laços e condições no template ({% for %} / {% if %})
  • Modelar dados como dicionários e listas
  • Ler os logs do servidor (200, 404, 405, 302, 500)
